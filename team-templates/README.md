# Team context

Shared, **committed** context for everyone working in this repo (people and AI agents). It lives next to the code and goes through code review.

- Rules here win over any personal `.context/`.
- Keep it short and factual. No secrets, no personal preferences, no work-in-progress notes (those belong in each person's own `.context/`).
- Files: `workflow.md` (branching, PRs), `security.md` (required practices), `conventions.md` (style and commands). Add others only when the whole team needs them.
- Agents are told to read this folder first. See `.context/START_HERE.md`.
