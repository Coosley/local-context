# Sessions

Per-agent session notes, for when several agents, tools or worktrees work in parallel.

- One file per session: `YYYY-MM-DD-<agent>-<slug>.md`.
- Write: what you are doing, files you touch, decisions made, what is left.
- Don't edit another session's file.
- When a session ends, fold anything durable into the shared files (plans, `decisions.md`, `gotchas.md`, `log.md`). Old session notes can be moved to `archive/`.
